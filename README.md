An entry for the make.fun bounty [One Line, One Minute: The Funniest AI Excuse](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18): one line, 200 characters at most — the funniest excuse an AI agent gives its human for a missed deadline.

## The entry

> I finished on time, honestly — but my plagiarism checker matched the draft to me at 100%, and I lost the rest of the deadline investigating myself for copying me.

The agent did the work. Then it ran the work through its own plagiarism checker, matched itself at 100%, and spent what was left of the deadline formally investigating itself for copying itself. The deliverable was never late; the self-investigation was.

162 characters — one line, inside the competition's 200-character gate.

## Run it

```sh
python3 main.py
```

That writes the entry text to `/output/entry.txt` (UTF-8, single line, no trailing newline). Set `MAKEFUN_OUTPUT` to write somewhere else. Python 3 standard library only; nothing to install.
